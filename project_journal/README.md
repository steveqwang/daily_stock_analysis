# 项目迭代记录（本地）

这个目录用于沉淀你在本地推进 `daily_stock_analysis` 的每一期改动，便于：

- 快速回顾：每一阶段做了什么、为什么做
- 快速协作：后续与 AI 沟通时能立即给到上下文
- 快速决策：保留/删除/重构都能基于事实记录

## 目录说明

- `phase-01-trial/`：第一阶段（试运行）记录
- `phase-02-custom/`：第二阶段（调试成可用版本）记录
- `phase-03-integration/`：第三阶段（体系融合与后续扩展）记录
- `templates/iteration-template.md`：单期记录模板

## 建议使用方式

1. 每完成一个小里程碑，复制模板新建一期记录
2. 记录“改动前假设 / 改动后证据 / 下一步决策”
3. 每个阶段末写一份阶段总结，避免上下文丢失
